# Напольные вешалки — Интернет-магазин

## 1. Описание проекта
Интернет-магазин по продаже стильных напольных вешалок и стоек для одежды. Минималистичный дизайн в чёрно-белой гамме, скандинавский стиль. Целевая аудитория — люди, ценящие эстетику и функциональность в интерьере.

## 2. Структура страниц
- `/` — Главная (hero, избранные товары, преимущества)
- `/catalog` — Каталог товаров (10-20 товаров, фильтры, сетка)
- `/product/:id` — Карточка товара (фото, описание, цена, кнопка в корзину)
- `/cart` — Корзина (список, количество, итого)
- `/login` — Вход
- `/register` — Регистрация
- `/profile/orders` — История заказов

## 3. Основные функции
- [ ] Каталог товаров с сеткой и фильтрами
- [ ] Карточка товара с галереей
- [ ] Корзина (добавление, изменение количества, удаление)
- [ ] Регистрация и вход пользователей
- [ ] История заказов в личном кабинете
- [ ] Адаптивный дизайн

## 4. Модель данных

### Таблица: products
| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | Первичный ключ |
| name | text | Название товара |
| price | integer | Цена |
| description | text | Описание |
| image_url | text | Фото |
| category | text | Категория |
| created_at | timestamp | Дата создания |

### Таблица: orders
| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | Первичный ключ |
| user_id | uuid | FK → users.id |
| status | text | Статус заказа |
| total | integer | Сумма |
| created_at | timestamp | Дата создания |

### Таблица: order_items
| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | Первичный ключ |
| order_id | uuid | FK → orders.id |
| product_id | uuid | FK → products.id |
| quantity | integer | Количество |
| price | integer | Цена на момент заказа |

## 5. Бэкенд / Интеграции
- **Supabase**: Хранение пользователей, корзины, заказов. Нужно подключить.
- **Оплата**: Позже (Stripe / Toss Payments)

## 6. План разработки по фазам

### Фаза 1: Главная + Каталог + Карточка товара
- Цель: Стильный UI магазина с мок-данными
- Результат: Главная страница, каталог с 12-16 товарами, страница товара

### Фаза 2: Корзина
- Цель: Локальная корзина (localStorage)
- Результат: Добавление в корзину, изменение количества, страница корзины

### Фаза 3: Supabase — регистрация и вход
- Цель: Подключить базу данных, регистрация и вход
- Результат: Страницы логина и регистрации, защита корзины

### Фаза 4: История заказов
- Цель: Сохранение и отображение заказов
- Результат: Страница истории заказов в личном кабинете

### Фаза 5: Онлайн-оплата
- Цель: Stripe / Toss Payments интеграция
- Результат: Оплата заказов онлайн
